## Prerequisites

- Python 3.11+
- Node.js 20+
- OpenAI API key with access to `gpt-4o-mini`
- Two terminal windows

---

## Environment Setup

### Backend (`backend/`)

Create `backend/.env`:

```bash
OPENAI_API_KEY=sk-your-key-here
OPENAI_MODEL=gpt-4o-mini
CORS_ORIGINS=http://localhost:3000
LOG_LEVEL=INFO
```

Install and run (commands finalized in tasks; expected shape):

```bash
cd backend
pip install -e ".[dev]"
uvicorn app.main:app --reload --port 8000
```

Verify:

```bash
curl http://localhost:8000/health
# Expected: {"status":"ok"}

curl http://localhost:8000/ready
# Expected: {"status":"ready","knowledge_loaded":true}
```

### Frontend (`frontend/`)

Create `frontend/.env.local`:

```bash
NEXT_PUBLIC_API_BASE_URL=http://localhost:8000
```

Install and run:

```bash
cd frontend
npm install
npm run dev
```

Open: http://localhost:3000

## Validation Scenarios

### VS-1: Core triage — billing complaint (P1)

**Maps to**: User Story 1, FR-002–FR-007, SC-001

1. Open the app; confirm sample prompt chips visible (≥3).
2. Click **Angry billing complaint** chip (or paste a duplicate-charge message).
3. Submit and wait for response.

**Expected**:
- Triage badges show `billing` topic, elevated urgency, frustrated/negative sentiment
- Response tone is empathetic and billing-focused
- Complete within ~30 seconds

**API check**:

```bash
SESSION=$(curl -s -X POST http://localhost:8000/api/v1/sessions | jq -r .session_id)
curl -s -X POST "http://localhost:8000/api/v1/sessions/$SESSION/messages" \
  -H "Content-Type: application/json" \
  -d '{"message":"I was charged twice for order ORD-12345. This is unacceptable!"}' | jq .
```

### VS-4: Multi-turn follow-up (P2)

**Maps to**: User Story 3, FR-008–FR-009, SC-005

1. Submit: "I need a refund for order ORD-12345."
2. Follow up: "How long will that take?" (without repeating order context)

### VS-5: Knowledge grounding with citations (P2)

**Maps to**: User Story 4, FR-010–FR-012, SC-006

**Expected**:

### VS-6: Mock order/account lookup (P3)

## SSE Stream Manual Test

```bash
SESSION=$(curl -s -X POST http://localhost:8000/api/v1/sessions | jq -r .session_id)
curl -N -X POST "http://localhost:8000/api/v1/sessions/$SESSION/messages/stream" \
  -H "Content-Type: application/json" \
  -d '{"message":"My account ACC-99 shows the wrong plan."}'
```

**Expected event sequence** (order may vary slightly before `done`):
1. `event: triage` — JSON metadata
2. `event: token` — one or more chunks
3. Optional `event: lookup`, `event: citations`
4. `event: done` — full TurnResponse

## Troubleshooting

| Symptom | Likely cause | Fix |
|---------|--------------|-----|
| CORS error in browser | Backend CORS misconfigured | Set `CORS_ORIGINS=http://localhost:3000` |
| 503 on `/ready` | Knowledge index not loaded | Check `backend/data/knowledge/` exists |
| Empty triage rationale | LLM parse fallback | Check logs; verify API key |
| Stream stalls | Timeout too low | Increase chain timeout in settings |
